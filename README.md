# Tamagotcha

A Chrome Extension for studying and keeping accountability via a virtual pet. The project is split into two main components: a browser extension (Frontend) and an Express server (Backend).

## Architecture Overview

### 1. The Chrome Extension (`/Extension`)
The frontend is built as a Chrome Extension using JavaScript, HTML, and CSS. It manages the user interface, study timers, and local state.

*   **Background Service Worker (`background.js`)**: 
    *   **State Management**: Maintains the core state in `chrome.storage.local`, including pet health, status, study timers, and user statistics.
    *   **Timers & Rewards**: Handles "work" and "break" sessions. Completing a work session increases the pet's health based on the time studied.
    *   **Site Blocking & Punishment**: Monitors active tabs. If a user navigates to a banned site (e.g., Facebook, Instagram, Reddit) during a work timer, it redirects them away and applies a health penalty for the violation. Penalty is 5% of max health each time. 
    *   **Pet Lifespan**: The pet can die if its health reaches 0 from violations, or from a week of inactivity.
*   **Popup UI (`popup.js` & `popup.html`)**: 
    *   Provides the primary interface to start, pause, and set custom study timers.
    *   Manages user authentication via Google OAuth.
*   **Options Page**: A configuration page to customize the list of banned websites during study sessions.

### 2. The Backend Server (`/Backend`)
The backend is a Node.js and Express server written in TypeScript. It provides a REST API backed by Firebase to persist the user's progress and cross-device sync.

*   **Authentication (`middleware/auth.ts`)**: Verifies tokens generated by the extension's Google OAuth flow to authenticate API requests.
*   **API Routes**: 
    *   `/api/v1/pets`: Stores and retrieves the user's pet state (health, status, accessories).
    *   `/api/v1/stats`: Tracks overall user statistics, such as total hours studied, pets killed, and longest pet lifespan.
    *   `/api/v1/sites`: Manages custom banned site lists.
